# 工事写真台帳

山﨑塗装のiPhone／iPad Safari向け工事写真台帳PWAです。  
表紙入力、横向き写真の圧縮・配置、入力データ保存／読込、PDF作成に対応します。

## 公開ページ

https://jzjy88kdfn-hash.github.io/yt-photo-ledger/

公開画面には簡易ロックがあります。入力した現場情報と写真を外部へ送信する処理はありません。

## 基本操作

1. 表紙情報を入力
2. 写真台帳へ横向き写真を追加
3. 工種と説明を入力
4. 「入力データ保存」でJSON控えを保存
5. 「PDF作成」で内容を確認してPDF保存

## PWA

Safariの共有メニューから「ホーム画面に追加」できます。初回オンライン起動後は、キャッシュ済みの画面をオフラインで起動できます。

## 重要

簡易ロックは、GitHub Pages上の画面を見えにくくするためのものです。サーバー認証ではないため、強い機密保護にはなりません。大切な入力データはJSONで控えを残し、作成したPDFは提出前に必ず開いて確認してください。
