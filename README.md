# 工事写真台帳

iPad / iPhone Safariで使う工事写真台帳です。
写真を入れて、表紙と写真台帳をPDFで保存できます。

公開ページはパスワード「2580」の簡易ロック付きです。入力した現場情報・写真は外部送信しません。

## 使うファイル

最初に開くファイルは `index.html` です。

## 基本の流れ

1. `index.html` を開く
2. 表紙情報を入力する
3. 写真台帳に写真を入れる
4. 工種と説明を入力する
5. 必要に応じて「保存」を押す
6. 「PDF」を押してPDFとして保存する

## 注意

写真をたくさん入れる場合は、途中で必ず「保存」を押してください。
Safariを閉じる前にも「保存」を押すと安全です。

## PWA

Safariの共有から「ホーム画面に追加」できます。初回のオンライン起動後は、ホーム画面からオフライン起動できます。
