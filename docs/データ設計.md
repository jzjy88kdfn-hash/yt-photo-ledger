# データ設計

## 現行構成

公開画面と写真台帳処理は `index.html` にまとめています。  
`access.js` は簡易ロックとService Worker登録、`service-worker.js` はオフライン起動用キャッシュを担当します。

|ファイル|役割|
|---|---|
|`index.html`|画面、写真圧縮、入力、JSON保存・読込、印刷PDF|
|`access.js`|簡易ロック、Service Worker登録|
|`manifest.webmanifest`|ホーム画面追加用設定|
|`service-worker.js`|公開ファイルのオフラインキャッシュ|
|`icons/icon-photo-1254.png`|画面ロゴ、ホーム画面アイコン|

## 保存データ

「入力データ保存」は、端末へJSONファイルをダウンロードします。外部サーバーへの送信や自動保存は行いません。

```json
{
  "cover": {
    "siteName": "",
    "workName": "",
    "startDate": "",
    "finishDate": "",
    "contractorName": "",
    "showContractor": "yes"
  },
  "compression": "middle",
  "entries": [
    {
      "no": "1",
      "work_type": "",
      "notes": ["", "", "", ""],
      "image": ""
    }
  ]
}
```

圧縮設定は `strong`、`middle`、`light` の3種類です。自由入力欄は4行、写真表示は枠いっぱい固定です。PDFは表紙1ページと、1ページ3枚の写真台帳で構成します。
