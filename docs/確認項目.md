# 確認項目

## 入力

- 現場名・工事名・施工者が正しい
- 着工・竣工が正しい
- 施工者の表示／非表示が希望どおり

## 写真台帳

- すべて横向き写真
- 不要な写真がない
- No.が順番どおり
- 工種と自由入力4行に誤字がない
- 写真枚数とページ数が正しい

## 保存

- 作業途中で「入力データ保存」を実行した
- 保存したJSONを必要に応じて読み込める
- PDF作成前にもJSON控えを保存した

## PDF

- 表紙が1ページ
- 写真ページは1ページ3枚
- 写真のない枠は出力されない
- 写真・文字・罫線が欠けていない
- ページ順が正しい
- 保存後のPDFを開いて確認した
