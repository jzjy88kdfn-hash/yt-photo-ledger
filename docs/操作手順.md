# 操作手順

## 1. 開く

公開URLをSafariで開き、簡易ロックを解除します。ホーム画面から使う場合は、Safariの共有メニューで「ホーム画面に追加」を選びます。

## 2. 表紙を入力

現場名、工事名、施工者、着工、竣工、施工者表示の有無を入力します。

## 3. 写真を追加

「写真台帳」を開き、各枠の「写真追加」から横向き写真を選びます。縦向き写真は登録されません。圧縮は大・中・小から選べます。

## 4. 台帳を入力

No.、工種、自由入力4行を入力します。必要に応じて枠追加、No.振り直し、写真削除、コメント削除、枠削除を使います。

## 5. 控えを保存

「入力データ保存」でJSON控えを端末へ保存します。作業を再開するときは「入力データ読込」を使います。自動保存ではないため、途中でも手動保存してください。

## 6. PDFを作成

「PDF作成」を押し、表紙・写真枚数・ページ数・保存候補名を確認してから印刷画面へ進みます。iPhone／iPadでは共有操作からPDFをファイルへ保存します。

## 7. 提出前確認

保存したPDFを開き、文字、写真、No.、罫線、ページ順を確認します。
